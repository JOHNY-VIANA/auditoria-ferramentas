# 🔧 Sistema de Auditoria de Ferramentas Industriais

Sistema web desenvolvido para auxiliar no controle, auditoria e gestão visual de ferramentas industriais, proporcionando maior organização operacional, monitoramento de indicadores e otimização dos processos da ferramentaria.

---

## 📌 Funcionalidades

✅ Dashboard operacional interativo  
✅ Controle e auditoria de ferramentas  
✅ Indicadores em tempo real  
✅ Gráficos estatísticos  
✅ Controle de avarias  
✅ Gestão por setores  
✅ Interface moderna e responsiva  
✅ Organização visual de dados  

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Chart.js

---

## 🎯 Objetivo do Projeto

O objetivo deste sistema é melhorar o gerenciamento e rastreamento de ferramentas industriais, proporcionando maior eficiência operacional, organização e suporte à tomada de decisão através de indicadores visuais.

---

## 🏭 Aplicação

Projeto voltado para:
- PCM (Planejamento e Controle de Manutenção)
- Ferramentaria
- Almoxarifado Industrial
- Gestão Industrial
- Controle Operacional
